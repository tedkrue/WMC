# Flukeout – CSS Diner

Übung zu CSS-Selektoren mit dem Lernspiel [CSS Diner](https://flukeout.github.io/).

In 32 Leveln muss man mit dem passenden CSS-Selektor die richtigen Elemente auf einem Tisch auswählen.

## Ergebnis

Alle **32 von 32 Leveln** gelöst. Der Screenshot `Flukeout gelöst.png` zeigt das abgeschlossene Spiel.

## Gelernte Selektoren (Auswahl)

- Element-, Klassen- und ID-Selektoren (`p`, `.klasse`, `#id`)
- Nachfahren- und Kind-Selektoren (`a b`, `a > b`)
- Geschwister-Selektoren (`a + b`, `a ~ b`)
- Pseudo-Klassen (`:first-child`, `:nth-child()`, `:only-of-type`, `:empty`, `:not()`)
- Attribut-Selektoren (`[attr]`, `[attr="wert"]`, `[attr^="..."]`, `[attr$="..."]`, `[attr*="..."]`)
