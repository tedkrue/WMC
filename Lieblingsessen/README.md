# 🍗 Chicken Alfredo Rezept

Eine einfache Webseite mit einem Rezept für Chicken Alfredo Pasta — cremig und lecker.

## 📖 Über das Projekt

Diese Seite zeigt eine Schritt-für-Schritt-Anleitung zur Zubereitung von Chicken Alfredo Pasta, inklusive Zutatenliste und Zubereitungshinweisen.

## 🛠️ Technologien

- HTML
- CSS

## 🚀 Wie man es startet

1. Repository klonen:

```bash
   git clone https://github.com/DEIN-USERNAME/lieblingsessen.git
```

2. `index.html` im Browser öffnen

Oder die Live-Version besuchen: [lieblingsessen](https://DEIN-USERNAME.github.io/lieblingsessen/)

## 🍽️ Zutaten (kurzer Überblick)

- Hähnchenbrust
- Fettuccine Nudeln
- Kochsahne
- Parmesan
- Knoblauch
- Butter
