## Lab02 – IT-Zitate

Das Projekt liegt gezippt im Repository (`lab02-it-zitate.zip`). Inhalt:

```
lab02-it-zitate/
├── css/          Stylesheet
├── imgs/         Bilder der IT-Gurus und Logo Spengergasse
├── screenshots/  Screenshots der HTML/CSS-Validierung
└── index.html
```

- Layout mit semantischen HTML5-Elementen (`header`, `main`, `footer`)
- Tabelle mit `colspan`, zentriert mit 70 % Breite
- Google Fonts: Roboto und Mali
- Zusätzliches Zitat von Linus Torvalds inkl. Bild
- Footer mit Name, Klasse und Logo Spengergasse
