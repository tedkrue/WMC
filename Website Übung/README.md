# Website Übung – Erste HTML-Seite

Die erste Übung im Fach WMC: eine einfache HTML-Seite ohne CSS, um die wichtigsten HTML-Elemente kennenzulernen.

## Inhalt

- Überschriften (`h1`, `h3`, `h4`) und Absatz mit einer kurzen Vorstellung
- Ungeordnete (`ul`) und geordnete (`ol`) Liste
- Bild (Logo Spengergasse)
- Link zur Schulwebseite
- Einfache Tabelle mit Kopfzeile

## Dateien

- `main.html`: die Webseite
- `images.jpeg`: Logo Spengergasse

## Starten

`main.html` im Browser öffnen.
